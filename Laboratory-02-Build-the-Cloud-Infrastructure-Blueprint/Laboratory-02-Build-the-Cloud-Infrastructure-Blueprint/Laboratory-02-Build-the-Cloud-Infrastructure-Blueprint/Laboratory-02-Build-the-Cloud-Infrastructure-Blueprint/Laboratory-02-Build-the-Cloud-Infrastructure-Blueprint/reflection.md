# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute is one of the most important cloud infrastructure components because it provides the processing power needed to run applications and services. Without compute resources, applications would not be able to process information or perform tasks. It also allows organizations to use virtual servers instead of maintaining expensive physical computers.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and reliable operating system for servers. It can manage computing resources, storage, networking, and applications efficiently. Linux is also commonly used in cloud environments because it is flexible, secure, and supports many different cloud technologies.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps organize and explain how an infrastructure should be configured. It allows administrators and developers to understand the resources, connections, and requirements before deployment. Good documentation can also help prevent mistakes and make troubleshooting easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use Linux commands to check information about a server, including the operating system, CPU, memory, storage, hostname, and IP address. I also learned how to compare AWS, Microsoft Azure, and Google Cloud services. In addition, I improved my skills in using GitHub, Markdown, and creating a basic cloud infrastructure diagram.
