
# Laboratory Activity 2

## Mission 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the basic components of cloud infrastructure. I investigated a Linux server using the KillerCoda Playground, identified its compute, storage, networking, and operating system resources, compared major cloud providers, and created a simple cloud infrastructure diagram.

## Objectives

* Explain the major components of cloud infrastructure.
* Investigate the hardware and software resources available in a Linux environment.
* Differentiate compute, storage, networking, and identity resources.
* Understand how cloud infrastructure components work together.
* Compare the core infrastructure services of AWS, Microsoft Azure, and Google Cloud Platform.
* Create technical documentation using Markdown.
* Create a simple cloud infrastructure diagram.

## Cloud Infrastructure Components

The main infrastructure components identified in this activity are compute, storage, networking, and the operating system. Compute provides processing power, storage keeps data and files, networking allows systems to communicate, and the operating system manages the server's hardware and software resources.

## Linux Commands Executed

The following Linux commands were used to investigate the cloud server:

```bash
cat /etc/os-release
uname -r
lscpu
nproc
free -h
df -h
mount
hostname
hostname -I
```

These commands were used to identify the operating system, kernel version, CPU, number of CPU cores, RAM, disk capacity, mounted file systems, hostname, and IP address.
