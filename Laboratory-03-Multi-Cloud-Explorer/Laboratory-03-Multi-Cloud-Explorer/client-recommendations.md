# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides scalable cloud services that can support a mobile application as the company grows. The startup can begin with smaller resources and increase them as the number of users increases. AWS also provides many services that can help reduce the need to maintain physical infrastructure. The company can use Amazon EC2, Amazon S3, and Amazon RDS to build and support its application.

**Recommended Services:**

* Amazon EC2 – for running the application
* Amazon S3 – for storing files and application data
* Amazon RDS – for managing the application's relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make cloud migration and identity management easier. The university can gradually move selected services to Azure while continuing to use its existing Microsoft environment. Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage can support the university's cloud requirements.

**Recommended Services:**

* Azure Virtual Machines – for running Windows-based workloads
* Microsoft Entra ID – for identity and access management
* Azure Blob Storage – for storing files, documents, and backups

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a strong choice for the AI research company because it provides cloud infrastructure and services suitable for Artificial Intelligence and Machine Learning workloads. The company requires high-performance computing, and Google Cloud can provide scalable computing resources for demanding workloads. GCP also has strong support for data, AI, and machine learning development. The company can use Compute Engine, Google Kubernetes Engine, and Cloud Storage for its projects.

**Recommended Services:**

* Compute Engine – for high-performance computing workloads
* Google Kubernetes Engine (GKE) – for deploying and managing containerized applications
* Cloud Storage – for storing datasets and research files

---
